# Profit and return analysis

Profitability and product-return analysis combining SQL, Python and Power BI for data cleaning, modeling and visualization. Built as an NTI graduation project.

## Contents
- `grad-project.pbix` - the Power BI source file
- `grad-project.ipynb` - the Python analysis notebook
- `SQLQuery1.sql`, `SQLQuery2.sql` - the SQL queries
- `NTI-grad-project.pptx` - the project presentation
- `pages/` - dashboard page screenshots

Part of [Youssef Sayed Hawass's data portfolio](https://youssefsayed025.github.io/portfolio/).
